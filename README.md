# 🌸 BloomCart - Online Flower & Gift Shop

BloomCart is a frontend website for flowers, gifts, and customized orders.

Customers can browse flower arrangements and gift sets, view product details,
customize their selected products, add items to a shopping cart, and review
their order before checkout.

## 🌷 Features

- Responsive homepage
- Flower and gift catalog
- Product details
- Product customization
- Shopping cart
- Quantity controls
- Order summary
- Checkout form
- Search and category filtering
- JavaScript interactivity

## 💐 Website Pages

- Home
- Shop
- Product Details
- Customize
- Shopping Cart
- Checkout
- About / Contact

## 🎀 Project Goal

BloomCart aims to provide a simple, attractive, and convenient online
flower-shopping experience where customers can browse products,
personalize gifts, manage their cart, and prepare their orders in one place.
