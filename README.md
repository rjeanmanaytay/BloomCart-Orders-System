# BloomCart
Frontend flower and gift shopping website based on the supplied BloomCart presentation.

Open `index.html` with Live Server.

Pages: Home, Shop, Product Details, Customize, Cart, Checkout, About/Contact, and Sign In/Create Account.

Stack: HTML5, CSS3, JavaScript. Cart and demo account data use localStorage. Account sign-in is browser-local only and is not secure server authentication; do not use real or reused passwords.
